# Ремонт на покриви — Иван Георгиев (Варна)

Едностраничен сайт визитка за майстор покривчия. **Целият сайт е в един файл** —
`index.html` (HTML + CSS + JS + SVG лого и икони). Без билд, без библиотеки, без
външни заявки.

## Стартиране

Двоен клик върху `index.html`, или локален сървър:

```bash
python3 -m http.server 8000   # → http://localhost:8000
```

## Снимки

Илюстрациите в „Преди / След“ са векторни (SVG), за да е сайтът един файл и да
зарежда мигновено. За реални снимки заменете `<svg>` в `.ba-before` и `.ba-after`
с `<img src="..." alt="...">`.

## Формата

Сайтът е статичен — няма сървър. Формата валидира данните и подготвя готов текст,
който клиентът праща с един бутон по **Viber** или **SMS**. Снимката се прикача
директно в чата. За имейл вместо това: сменете бутоните с
`mailto:...?subject=...&body=...`.
