# Учебна програма и заместване

Статичен сайт (без сървър): отвори `index.html` в браузър.

- **Учители** – име, специалности, вид (учител / занималня) и свободни места на занималнята.
- **Програма** – седмична програма по клас (предмет + учител), с проверка за конфликти.
- **Заместване** – избираш дата и отсъстващи (цял ден или по часове); системата подбира заместници: специалист → занималня → свободен учител. При ново отсъствие целият ден се преизчислява оптимално, така че заместниците се пренареждат по специалност.
- **Данни** – примерни данни, резервно копие (JSON), настройки.

Данните се пазят в `localStorage` на браузъра.
